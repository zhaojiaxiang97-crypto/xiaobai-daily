# 组件预览

从 Electron 打包产物反编译出的 Vue 组件，**在隔离环境逐个渲染后截图**。

打开 `index.html` 就能看全部效果（图片是静态截图，不需要装依赖）。

## 数据

| 项 | 值 |
|---|---|
| 参与渲染的组件 | **107**（`main` 98 + `vendor` 9） |
| 实际渲染成功 | **102** |
| 失败 | 5（列在页尾，附原因） |

## 怎么生成的

1. 每个组件用**独立页面**加载（`one.html?name=X&group=Y`）——隔离错误，一个组件崩不影响别的
2. 真实 Chrome 通过 CDP 逐个导航、截图
3. 汇总成 `index.html` 的图片墙

**为什么不用单页画廊**：试过，组件模块的顶层代码会污染全局，
导致整页渲染崩掉（连只加载 3 个都失败）。隔离页面是唯一可靠的做法。

## 也能实时跑

```bash
cd ..          # 回到 vue/
npm install
npm run dev    # 访问 /one.html?name=Alert&group=components
```
