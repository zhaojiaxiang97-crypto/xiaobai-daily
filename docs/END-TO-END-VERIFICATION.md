### 关于页面内容数字的波动

断言逻辑是：

```python
ok = body > 100 and all(v > 20 for v in results.values())
```

**只检查非空，不比对具体数字。** 页面内容依赖运行时数据（如 `应用记录`
显示的是数据库里的记录条数），所以不同环境数字不同（历史记录里曾是 2441，
本轮是 653）—— 这是正常波动。

这个断言的意义是**立即发现「页面全空白」这类回归**（round-0400 的
import 别名批量改名、round-0402 的函数参数改名都曾导致过整页空白）。
